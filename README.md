# 💻 CS Quiz App

An interactive multiple-choice quiz application built with HTML, CSS, and JavaScript.

## Features
- 10 Computer Science questions
- Instant right/wrong feedback with green/red colors
- Score tracking and final result screen
- Progress indicator (Question X of 10)
- Play Again option

## Tech Stack
- HTML5
- CSS3 (Gradient design, animations)
- JavaScript (DOM manipulation)

## How to Run
1. Clone this repository
2. Open index.html in any browser
3. Start playing!
